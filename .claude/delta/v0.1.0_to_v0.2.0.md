# Delta Summary: v0.1.0 to v0.2.0

## API Changes

### Anthropic Client Integration
- **Changed**: Updated Anthropic SDK from v0.39.0 to v0.41.0
- **Added**: Support for webhook signature verification
- **Added**: Exponential backoff retry logic for API calls
- **Fixed**: Token calculation for batch summaries now properly aggregates completion values

### Authentication
- **Added**: Support for GitHub OAuth provider
- **Changed**: Session maxAge increased from 14 days to 30 days
- **Fixed**: JWT token now correctly includes user role

### Batch Processing
- **Added**: Batch cancellation endpoint
- **Added**: Batch cloning functionality
- **Fixed**: Status mapping function now handles all Anthropic API status values
- **Changed**: Improved error handling with more specific error messages

## Schema Changes

### Batch Model
- **Added**: `public` field (boolean) to allow sharing batches with team members
- **Added**: `tags` field (string[]) for batch categorization
- **Added**: `originalBatchId` field (string) for batch cloning reference

### User Model
- **Added**: `preferences` field (JSON) for storing user UI preferences
- **Added**: `lastActive` field (DateTime) for tracking user activity
- **Changed**: Expanded `role` enum with `TEAM_ADMIN` value

## UI Changes

- **Added**: Dark mode support
- **Added**: Batch filtering by status, model, and date range
- **Added**: CSV export for batch results
- **Added**: Batch cloning functionality in UI
- **Changed**: Improved responsive design for mobile devices
- **Changed**: Enhanced batch statistics visualization

## Performance Improvements

- **Added**: Pagination for batch list to improve load time
- **Added**: Optimistic updates for batch operations
- **Added**: Caching headers for static assets
- **Changed**: Server-side rendering for batch detail page

## Developer Experience

- **Added**: Storybook for component development and testing
- **Added**: Unit tests for critical components
- **Added**: End-to-end tests for critical flows
- **Changed**: Improved error messages and logging

## Migration Notes

1. Run database migrations: `npx prisma migrate dev`
2. Update environment variables:
   - Add `GITHUB_CLIENT_ID` and `GITHUB_CLIENT_SECRET` for GitHub OAuth
   - Add `ANTHROPIC_WEBHOOK_SECRET` for webhook verification
3. Review code that relies on batch statuses, as the mapping has been updated
